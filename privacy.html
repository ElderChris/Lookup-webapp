Informativa sulla privacy

Come Libreria Diffusa raccoglie, conserva e utilizza i tuoi dati personali.
Ultimo aggiornamento: giugno 2026.

1. Premessa importante

Libreria Diffusa è attualmente in fase di prototipo (release v3.0.0-alpha.0) in transizione verso una release Alpha closed. Nel prototipo attuale tutti i dati restano nel localStorage del tuo browser e non vengono inviati a nessun server. Nella release Alpha (prevista entro 3-4 mesi) sarà disponibile un deploy self-hostable via Docker compose dove i dati saranno persistiti in un database PostgreSQL gestito dal soggetto che ospita l'istanza.

Questa informativa descrive il comportamento previsto per la release Alpha. Le sezioni applicabili al solo prototipo attuale sono marcate con (solo prototipo).

2. Titolare del trattamento

(solo prototipo): nessun dato lascia il tuo browser, non c'è alcun trattamento centralizzato. Il prototipo è eseguibile in locale senza creare alcun account su servizi esterni.

(Alpha): il Titolare del trattamento sarà il soggetto che ospita l'istanza self-hostata. Nel deploy di test con il cliente, Titolare è il cliente stesso. In un eventuale deploy pubblico sarà indicato il nome dell'organizzazione titolare con i contatti DPO.

3. Dati che raccogliamo

Nel prototipo, i seguenti dati vengono salvati esclusivamente nella memoria locale del tuo browser (localStorage):

  • Dati di profilo: nome, username, email, città, biografia, eventuali dati identificativi degli enti (P.IVA, indirizzo legale).
  • Preferenze di personalizzazione: tema scelto, avatar, motto della libreria, lingue dei volumi pubblicati.
  • Catalogo dei volumi: titoli, autori, ISBN, condizioni, descrizioni, foto delle copertine generate dall'app.
  • Prestiti: richieste inviate, ricevute, stato corrente, motivazioni di rifiuto, messaggi della chat associata.
  • Recensioni: testo, valutazione a stelle, data.
  • Interazioni social: follower, libri preferiti.
  • Notifiche: tutti gli eventi che ti riguardano sulla piattaforma.

4. Servizi esterni utilizzati

L'interfaccia carica risorse da alcuni provider esterni, ognuno con la propria policy:

  • OpenStreetMap (mappe in Esplora) — l'IP del tuo dispositivo è visibile ai server delle mattonelle. Vedi osmfoundation.org/Privacy_Policy.
  • Open Library Covers API (copertine dei libri quando disponibili) — richieste HTTP per il caricamento delle immagini di copertina.
  • CDN per Leaflet, Chart.js e i font (Google Fonts) — caricamento di librerie e font tipografici dai loro server.

La piattaforma non utilizza cookie di tracciamento né strumenti di analytics (Google Analytics, Facebook Pixel e simili).

5. Email transactional

(solo prototipo): nessuna email viene inviata. Alcune azioni (avvio restituzione, sollecito, reset password) generano email "simulate" salvate nel tuo browser localStorage e visualizzabili in un box "🔧 Demo del prototipo" sulla pagina corrispondente.

(Alpha): il sistema invia email transactional (conferma registrazione, reset password, notifiche di prestito, alert moderazione) tramite SMTP. Nel deploy di test locale via Docker compose le email vengono catturate da MailHog (visibile su :8025) e non lasciano la macchina. In un deploy pubblico, il Titolare configura un proprio server SMTP (qualsiasi: del cliente, Postmark, AWS SES, Resend…).

6. I tuoi diritti (GDPR)

In conformità al Regolamento UE 2016/679 (GDPR), in produzione avresti diritto a:

  • Accedere ai tuoi dati personali
  • Rettificare informazioni errate
  • Cancellare il tuo account e tutti i dati associati
  • Esportare i tuoi dati in formato leggibile
  • Opporti a determinati trattamenti
  • Proporre reclamo all'Autorità Garante

Il prototipo implementa il diritto di esportazione dalla sezione Impostazioni del tuo profilo: il pulsante "Scarica i miei dati (JSON)" produce un file JSON con tutto quanto ti riguarda. Per la cancellazione, è sufficiente svuotare il localStorage del browser (Strumenti per sviluppatori → Application → Storage → Clear).

7. Sicurezza

I dati restano nel tuo browser e non vengono trasmessi a server centrali. Le password sono salvate come hash (sebbene il prototipo usi un algoritmo semplificato non adatto alla produzione). In produzione si applicherebbero bcrypt o argon2, HTTPS obbligatorio, rate limiting e tutte le buone pratiche di sicurezza standard.

8. Modifiche

Possiamo aggiornare questa informativa per riflettere cambiamenti nel funzionamento del servizio. La data in cima al documento indica l'ultima revisione.

9. Contatti

Per qualunque dubbio sul funzionamento del prototipo o sul trattamento dati descritto qui, contatta il gestore della piattaforma — per il prototipo accademico, l'autore del progetto.
